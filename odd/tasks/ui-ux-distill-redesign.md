# Feature: UI/UX Distill & Redesign

Objective: Rediseñar y destilar componentes clave de la UI/UX en `apps/web`: destilar `app-page-header` para eliminar envoltorio tosco de card y optimizar espacio vertical (~60px), integrar tema oscuro CartoDB Dark Matter en el mapa Leaflet de parking con estilos Zinc, y rediseñar la vista de tickets con Metric Ribbon interactivo, chips vehiculares de alto contraste, temporizador de estadía y acción directa de cobro. Branch: feat/rebranding-ux-overhaul Delivery Strategy: ask-on-risk Test Runner: vitest via @angular/build:unit-test (bun run --cwd apps/web test)

## Specs

- S1: Page Header Distillation: Remove bulky card wrapper from `app-page-header`. Convert to sleek horizontal flow saving ~60px vertical space, retaining breadcrumbs, title, badge and actions without card-in-card nesting.
- S2: Leaflet Map Dark Theme Integration: Use standard free OpenStreetMap tiles (100% free, $0 cost) with zero-cost CSS dark filter inversion on .leaflet-tile-pane matching Nivo Zinc OKLCH tokens, plus custom styled emerald radar marker.
- S3: Tickets Page & Table Overhaul: Add actionable Metric Ribbon on top (Active, Overtime/Alert, Closed today, Revenue) that filters the table on click. Redesign table columns to feature high-contrast vehicular plate chips, live duration indicator with progress bar, JetBrains Mono currency formatting, and direct checkout action.
- S4: Design System & Rules Compliance: All UI components must strictly use `@nivo-sass/design-system` (`nv-button`, `nv-badge`, `nv-card`, `nv-typography`). All text in `APP_TEXTS`. Zero hardcoded strings or raw HTML buttons/inputs. No emojis in templates. Enforce OnPush change detection.
- S5: Tickets Page & Table Mockup Full Parity:
  - 4-Card Actionable Telemetry Ribbon (En Permanencia/Activos with live pulse dot, En Alerta/Mora > 8h, Cerrados Hoy, Total Tickets) that filter table on click.
  - Vehicle filter pills (Todos, Carros, Motos) in toolbar.
  - Standard plates rendered in clean monospace typography without yellow badge styling or country tag; unplated retains camera icon.
  - Duration & Entry cell with formatted entry timestamp on upper line and relative elapsed duration on lower line without progress bar.
  - Table row click to open ticket detail drawer.
- S6: Parking Detail Page Mockup Full Parity:
  - Header operational shortcuts: ⚡ Taquilla Directa, Configurar Tarifas, Editar Sede.
  - Parking Telemetry Ribbon: Occupancy Gauge card (percentage, capacity ratio, linear gauge fill, and vehicle breakdown for Autos vs Motos), Recaudo Turno card, Rotación & Permanencia card.
  - Map Presentation Card: topbar with GPS coordinates and live dot, Leaflet dark map, and Operational Quick Dock Bar underneath (Auditar Bahías, Taquilla Directa, Configurar Tarifas).
  - Visual Bay/Slot Grid Matrix showing bays (A-01, A-02...) with mini plate chips or LIBRE tags and occupancy legend.

## Key Learnings

- Destiling container padding from `@sm:p-6` to `@sm:py-3 @sm:px-0` and removing card encapsulation gives headers natural flow while saving ~60px vertical height without altering inner layout slots or container query breakpoints.
- Leaflet default `divIcon` injects `.leaflet-div-icon` styling with white background and border; overriding `:host ::ng-deep .nivo-map-marker-container` with transparent background and zero border enables clean animated radar ping markers.
- Encapsulating table cell styling into dedicated standalone presentational components (`TicketTotalCellComponent`) via `flexRenderComponent` allows clean tabular-nums and typography styling in TanStack table definitions without polluting templates with conditional cell logic.
- Documenting user-driven UI refinements in ODD spec documents maintains complete auditability between live browser feedback and repository specifications.
- Replacing simulated mockup metrics with real data points from domain models prevents user confusion and builds trust in operational telemetry.
- Leaflet maps inside dynamic flex/grid cards require `:host { height: 100% }` and a `ResizeObserver` calling `map.invalidateSize()` to fill available vertical space without leaving tile rendering gaps.
- Agrupar rutas de navegación en secciones conceptuales ("Operación Diaria" y "Configuración & Fiscal") con resolución dinámica basada en la sede activa (ActiveParkingService) garantiza transiciones operativas sin fricción ni descontextualización de ID.
- Resolver dinámicamente el identificador activo priorizando `activeParkingLot().id` sobre `activeParkingId()` evita que ítems de navegación caigan en rutas por defecto cuando el almacenamiento local aún no ha hidratado la clave explícita pero el servicio ya resolvió la sede por defecto.
- Implementar el Sede Switcher con CDK Connected Overlay proporciona un selector contextual fluido que preserva la sub-ruta operativa actual (`/rates`, `/slots`) al conmutar entre diferentes parqueaderos sin interrumpir el flujo del usuario.
- Objetos de valor complejos de dominio (como `Address`) no deben interpolarse directamente en plantillas HTML de Angular; encapsular su formateo en un método helper o pipe defensivo con fallback numérico previene fugas de serialización `[object Object]` en la interfaz de usuario.
- Puente de navegación contextual vía query parameters (`checkoutTicketId`) desacopla las vistas de consulta masiva (tickets audit log) de las terminales operativas de caja (taquilla en vivo), permitiendo disparar transacciones de checkout con idempotencia tanto en cargas síncronas como asíncronas de datos.
