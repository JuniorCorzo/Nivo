# Propuesta: Dashboard Analítico, Métricas en Tiempo Real y API Pública de Disponibilidad (feat-nivo-dashboard)

## Meta y Justificación
Dotar a la plataforma Nivo de un centro de mando analítico integral y en tiempo real para administradores de parqueaderos, complementado con una API pública de alta concurrencia para integraciones con aplicaciones de navegación vehicular. La solución implementa vistas materializables/optimizadas en PostgreSQL (`v_parking_occupancy_hourly`, `v_parking_daily_summary`, `v_parking_operational_report`) e instrumentación de métricas de telemetría de negocio con Micrometer (`parking.occupancy.rate`, `parking.revenue.daily`, `parking.slots.*`), alimentando un motor de streaming reactivo basado en Server-Sent Events (SSE) vía `SseEmitter` desacoplado mediante eventos de dominio para actualizar métricas operativas al instante sin sobrecargar el servidor con sondeo continuo (polling). Asimismo, se expone un endpoint público de disponibilidad con control de tasa de consumo por Token Bucket (60 req/min por IP) y caché de corta duración, se simplifica la experiencia de pruebas interactiva en OpenAPI mediante un script de auto-autenticación pre-request integrado en Scalar, y se construye en Angular 21+ un Dashboard reactivo basado en `DashboardFacade` (Signals, consumo SSE mediante `fetch` + `ReadableStream` con Bearer token), gráficos analíticos avanzados en Chart.js (curvas horarias de ocupación con gradientes y donas de distribución de plazas), tablas operativas de alto rendimiento con TanStack Table, exportación continua de reportes en streaming CSV y adhesión rigurosa a los componentes del `@nivo-sass/design-system`.
